
# Atividade de Estrutura de Dados
Esse projeto demonstra de forma simples de como funciona o algoritmo **Insertion Sort**, usando a analogia fornecida pela professora, onde um entregador precisa inserir um **pacote urgente** em uma lista ordenada.

## História:
Um entregador organiza seus 10 pacotes no carro. Ele é esperto e já os deixou na ordem de entrega (nº 100,nº 110,nº 120,nº 150,nº 160,).
Exatamente no momento em que ele estava saindo, o gerente corre e entrega mais um pacote: "URGENTE! Leva este aqui também, da casa nº 115!".
O entregador não joga todos os pacotes para o reordenar. Ele pega o pacote 115 e o "insere" no lugar certo. Ele o compara com o 160 ("é menor"). Compara com o 150("é menor"). Compara com o 120 ("é menor"). Compara com o 110 ("é maior!"). "Opa, seu lugar é aqui, depois dos 110 e antes do 120.

## Objetivo da atividade: 
A professora pediu para que explicássemos o funcionamento do algoritmo **Insertion Sort**, usando uma situação do cotidiano de um entregador.

## O desafio
- Como inserir o pacote 115 na posição correta sem bagunçar o restante dos pacotes.
- Como pedir ao computador para ele olhar cada pacote e comparar se é menor ou maior.

#### A resposta é simples! 
Utilizamos o algoritmo fornecido **Insertion Sort**

## O algoritmo Insertion Sort
O computador não consegue "olhar tudo de uma vez". Ele precisa pegar o pacote 115 e comparar um por um com os que já estão no banco do carro do entregador.

## O que este código nos ensina?
- Como funciona o processo interno do Insertion Sort
- Como o algoritmo compara valores um por um
- A lógica de mover itens maiores para frente em uma lista
- A criação de um espaço vazio para inserir um novo elemento em uma lista
